# ⑤ 持有与风控手册

持有的目标不是"盯盘"，是**在触发条件出现时，第一时间知道规则怎么写的**。

## 一、三级检查节奏

| 频率 | 看什么 | 花多久 |
|---|---|---|
| 盘后每日 | 收盘价 vs 止损/止盈线；是否有公告；是否逾期复盘 | 3 分钟 |
| 每周 | 行业价格/景气度变化、同业公告、资金面（有息负债、质押） | 20 分钟 |
| 财报后 | 三张表 + 关键指标对照宪法里的验证项 | 1–2 小时 |

## 二、事件四类（比价格更重要）

1. **财报**：收入/利润/毛利率/现金流是否符合买时假设。
2. **公告**：减持、质押、诉讼、监管处罚、重大合同、变更审计机构。
3. **行业**：产品价格、上游成本、政策（补贴退坡、关税、限产）。
4. **股价**：触及止损/止盈、异常放量、连续跌停。

事件优先级高于价格：**价格触发只是提醒你读规则，事件触发才可能改变规则。**

## 三、触发后的动作顺序（不要跳步）

1. 先 `stock_os action=guards symbol=... price=...`，让规则先说话。
2. 读宪法里对应的那一条，逐字读，不要凭记忆。
3. 判断这是"规则内"还是"规则外"：
   - 规则内 → 执行，不再讨论。
   - 规则外（规则没覆盖的新情况）→ 先记录事实，再修改规则，再执行。**修改必须写理由**。
4. 执行 → `action=trade` → 流水。

## 四、风控红线（任何时候都不许破）

- 单只股票不超过 `maxPositionPct`。
- 组合层面：同行业合计不超过 30%；单一逻辑（如"AI 算力"）不超过 40%。
- 不用杠杆；不把生活备用金投进去。
- 连续 3 笔止损 → 强制停手 2 周，只做复盘，不开新仓。

## 五、可自动化的部分（DSH 定时任务）

| 任务 | 建议时点 | 内容 |
|---|---|---|
| 盘后检查 | 交易日 15:30 | 拉持仓股收盘价，跑 `guards`，把触及止损/止盈/逾期复盘的股票列出来 |
| 周度体检 | 周六 10:00 | 本周公告摘要 + 行业价格 + 组合集中度 |
| 财报提醒 | 财报预约日 T-3 | 提醒准备阅读清单与验证项 |

定时任务只允许：读取、计算、提醒、写 `journal kind=notice`。**不允许自动下单。**

## 六、持有的心理纪律

- 浮盈不是加仓理由，浮亏不是装死理由。
- 不看盘也可以持有：只要规则和提醒都在。
- 每天问一次："如果今天是我第一次看到这只股票，我还会买吗？"答案是否，就去看 `reduce`/`exit`。
