# ⑦ 清仓手册

清仓是唯一一个"一次卖完"的动作，所以它必须由**已经写下的条文**触发，而不是由当天的情绪触发。

## 一、四类清仓触发

| 编号 | 触发 | 说明 |
|---|---|---|
| exit-1 | 止损线 | 跌破宪法 `stopLossPct`，无条件执行 |
| exit-2 | 止盈达标 | 达到 `takeProfitPct`，全卖或留 1/3 观察仓 |
| exit-3 | 前提失效 | `invalidations` 命中（业绩、逻辑、治理、行业政策） |
| exit-4 | 机会成本 | 找到明显更优的标的，且这只已无超额收益（**慎用**，一年不超过 2 次） |

## 二、清仓前的三个确认

- [ ] 触发的是哪一条？把条文原文贴出来。
- [ ] 是否已经过了一夜？（不在情绪最烈的当天做清仓决定，止损除外）
- [ ] 卖完之后，钱去哪？（没有去处就先卖一半）

## 三、清仓后的强制动作

1. 流水里写一句：**"如果它之后继续涨 50%，我认了，因为___。"** 这句话是给未来的自己看的，防止追回。
2. `stage` 自动变为 `closed`。
3. **冷静期 5 个交易日**：不得重新买入同一标的，除非出现买前调研级别的新证据（并重新走一遍 research → plan）。
4. 一周内完成 `review` 手册的复盘。

## 四、常见错误

| 错误 | 后果 |
|---|---|
| 止损后当天追回 | 规则形同虚设，成本越摊越高 |
| 止盈后全卖，又在更高位买回 | 把一次成功的交易变成两次情绪交易 |
| 因为"已经亏这么多"而不清仓 | 沉没成本；亏损不是继续持有的理由 |
| 清仓不留记录 | 三个月后你会记成"我早就看出来了" |

## 五、记录

`stock_os action=trade trade=close qty=<全部持仓> price=... reason="触发 exit-1 ..." triggerId="exit-1"`

清仓后立刻 `action=journal kind=review-due`，并设 `reviewDueAt` 为 7 天内。
