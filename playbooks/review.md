# ⑧ 统计与复盘手册

复盘的目的是**区分本事和运气**，然后只改"本事"那部分。分不清这两者，复盘就会变成自我安慰或自我否定。

## 一、单笔复盘四问

1. **规则遵守了吗？** 有没有破例？破例几次？（流水里 `overrides` 就是证据）
2. **规则本身对吗？** 即使这次赚钱，规则是否也会在别的场景让你亏？
3. **信息够吗？** 当时的判断，用当时能拿到的数据，是合理推断还是猜测？
4. **如果重来，会怎么做？** 只写一条可执行的改动，不写"要更谨慎"。

## 二、归因：把结果拆成四格

| | 赚钱 | 亏钱 |
|---|---|---|
| 按规则做 | 应得的 → 继续 | 概率内的 → 接受，不必改 |
| 没按规则 | 危险的 → **重点复盘**（这次赢了会强化坏习惯） | 双重错误 → 重点复盘 |

**最危险的是"没按规则但赚钱"**，它会让下一次更敢破例。

## 三、组合层面的统计（每季度一次）

| 指标 | 怎么算 | 用来判断 |
|---|---|---|
| 胜率 | 盈利笔数 ÷ 总笔数 | 低于 40% 不一定是问题，看盈亏比 |
| 盈亏比 | 平均盈利 ÷ 平均亏损 | 胜率 40% + 盈亏比 2 就是好系统 |
| 最大回撤 | 账户净值峰值回落 | 超过 20% 说明仓位管理有问题 |
| 纪律违约率 | 破例次数 ÷ 总动作次数 | >10% 说明规则不适合你，不是你不自律 |
| 平均持有期 | 天 | 与策略类型是否匹配 |
| 换手率 | 年度交易额 ÷ 平均市值 | 过高说明在被消息驱动 |

## 四、改规则的正确姿势

只有当同一条规则**连续两次**导致可识别的错误时，才改。改的时候写三行：

```
原规则：<原文>
新规则：<新文>
依据：<哪两笔交易、什么数据、为什么旧规则错了>
```

通过 `stock_os action=constitution` 更新，并在 `journal kind=rule-change` 里留档。**不允许"悄悄改"——那等于给自己开后门。**

## 五、季度复盘清单

- [ ] 每笔已平仓交易都有 review 记录
- [ ] 破例记录逐条回看：是规则问题还是执行问题
- [ ] 三个数字：胜率、盈亏比、最大回撤
- [ ] 一条要改的规则（最多一条）
- [ ] 下季度不开新仓的条件（什么情况下我应该空仓）

## 六、写进流水

`stock_os action=journal kind=review symbol=... text="四问答案 + 归因 + 一条改动"`

复盘的价值不在写得长，在于**下个季度你还会翻它**。
