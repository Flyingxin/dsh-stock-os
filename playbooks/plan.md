# ② 策略宪法手册

目标：把调研结论翻译成**一组不会在情绪里被改掉的数字**。宪法的价值不在写得漂亮，而在于它是在你没亏钱、也没赚钱的时候写的。

## 一、宪法必备的十一个字段

| 字段 | 含义 | 怎么写才不会后悔 |
|---|---|---|
| `maxPositionPct` | 这只股票最多占总资金多少 | 用"如果明天跌 30% 我还能睡着"来定 |
| `tranches` | 分几笔建完 | 3 笔是默认；资金量小的 2 笔 |
| `firstTranchePct` | 首笔占总资金多少 | ≤ 上限 ÷ 分批数，通常 2–3% |
| `stopLossPct` | 止损线 | 设在"论证错了"的位置，不是设在"我难受"的位置 |
| `maxDrawdownPct` | 这笔交易允许的最大回撤 | 触发即进入复盘，不是自动清仓 |
| `takeProfitPct` | 止盈线 | 可以分批止盈；周期股要给得宽 |
| `addRules` | 什么条件才加仓 | 必须写"验证了什么"，不能写"跌了就加" |
| `reduceRules` | 什么条件减仓 | 估值、仓位超标、逻辑弱化三类分开写 |
| `exitSignals` | 清仓信号（≥1 条） | 每条都要可观察，能落到一个数字或一份公告 |
| `invalidations` | 前提失效条件（≥1 条） | "基本面恶化"不算，要写"毛利率连续两季低于 15%"这种 |
| `reviewCadenceDays` | 多少天复盘一次 | 30–90 天；财报季缩短到 7 天 |

## 二、回撤预案（`plans.drawdownPlan`）

建仓之前必须回答：

1. 跌多少，我承认这笔判断错了？（通常等于止损线）
2. 到那个位置，我是清仓、减半，还是重读一遍财报再决定？
3. 如果跌的原因是"市场整体"，规则要不要例外？（提前写，别临场想）
4. 如果它涨到止盈线，我是全卖还是留一半？

一句示例：**"跌破 18.4 元（−15%）先减半；若同时出现季报毛利率低于 15%，清仓；若只是大盘跌而公司数据未变，减半后留观察仓。"**

## 三、三种最常见的坏宪法

| 坏宪法 | 为什么坏 | 改成 |
|---|---|---|
| "跌破 5% 止损" | 被日内噪音打掉，反复交易 | 按波动率或关键位设，通常 10–20% |
| "基本面变坏就卖" | 无法执行，永远可以狡辩 | 写成可读的指标与阈值 |
| "看好就满仓" | 没有分批，一次错误就出局 | 分 3 笔，首笔 ≤ 3% |

## 四、写完之后做一次压力测试

把宪法读一遍，问三个问题：

- 如果明天跌 20%，我按这条规则做，会不会觉得"当初写错了"？会 → 规则太紧。
- 如果明天涨 50%，我会不会后悔没多买？会 → 仓位上限太保守，也别改，记住这个感觉就够了。
- 这几条规则里，有没有哪条是"为了让今天能买"而写的？有 → 删掉重写。

## 五、落库

```
stock_os action=constitution symbol=... constitution={...}
stock_os action=plan symbol=... drawdownPlan="..." reviewDueAt="2026-03-31"
```

写完后 `action=stage to=plan`。**此后任何一次修改宪法，都要在流水里写清"改哪条、为什么、哪次失败让你改的"。**
