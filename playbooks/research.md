# ① 买前调研手册

目标：在花一分钱之前，把这笔投资变成一个**可以被证伪的判断**。输出只有一个东西——`verdict`，以及支撑它的证据出处。

## ⓪ 数据准入（硬门槛，不做完不许出结论）

`stock_os verdict` 会检查这一步：没有通过检查的近五年财报数据，结论写不进去。

1. **收集近五年年报与最新季报的关键科目**，写进 `stock_data action=set`：
   - 市场：A/H 用 `600519.SH` / `00700.HK`；美股用 `AAPL` / `AAPL.US` / `TSLA.NASDAQ`（裸代码会归一成 `*.US`）。
   - 货币单位写进 `unit`：A 股常用 `亿元`，美股常用 `百万美元` / `十亿美元`，前后保持一致即可。
   - 必填三条主干：`revenue` 营业收入、`netProfit` 归母净利润（美股对应 net income attributable to common）、`opCash` 经营活动现金流净额（**五年都不能有空值**）。A/H 去年报；美股去 10-K / 10-Q / annual report。
   - 再补至少 3 项：`grossMargin` 毛利率、`receivables` 应收、`inventory` 存货、`cash` 货币资金、`debt` 有息负债、`totalAssets` 总资产、`equity` 归母净资产、`roe`、`pe`、`pb`、`dividend`、`capex`、`equityRaise`。
   - 每个数组长度必须等于 `years`，某年真拿不到就写 `null`（图上会留缺口，不会编数）。
2. `stock_data action=check` 复查，直到返回"数据完整"。差什么，它会告诉你科目名和**去报表哪一行拿**（提示按 A 股科目口径；美股自行对应到同名 IFRS/US-GAAP 行）。
3. 数据不完整时只有两条路：补齐，或 `verdict` 时显式 `force: true` + `overrideReason`（会留痕，复盘时要解释）。

顺序固定的原因：先有数，才有图；先有图，才有判断；先有判断，才写规则。反过来做的，都是在给自己找理由。

## 一、行业与生意（先看生意，再看报表）

| 问题 | 要求 |
|---|---|
| 这门生意卖什么、卖给谁、怎么收钱 | 一句话讲清，出现"综合解决方案"这类词就重写 |
| 行业空间与增速 | 给数字与来源，不要"前景广阔" |
| 行业集中度与公司位置 | CR5/市占率；份额在升还是在降 |
| 周期位置 | 强周期行业必须判断"在周期的哪一段"，并说明依据 |
| 上下游议价 | 谁能占款：应收、预付、应付、合同负债四个方向的强弱 |
| 护城河类型 | 品牌 / 成本 / 网络 / 转换成本 / 牌照，**必须给证据**（毛利率差、客户留存、单吨成本对比） |

护城河的判据只有一条：**同样的东西，它凭什么能持续比同行多赚，或同样赚钱却更难被替代。** 说不出证据的，就是没有。

## 二、财务底稿（用笔记当检索器，不重新发明）

- 底稿：8 章 132 节笔记已经装成工具。**先搜再读**：`stock_notes action=search query="净现比"`，拿到"第几节 + 原句"，结论里引用节号（如"依据第 44 节"），而不是凭记忆复述。
- 需要整本翻：`stock_notes action=toc` 看九部分，`action=toc part=4` 看第 4 部分全部节号；`action=emit symbol=<代码>` 生成带调研对象水印的 HTML（可 `section=55` 直接落到某一节）。
- 排雷：第 20 份结论报告的 12 项固定检查 + 6 条硬性排除条件。
- 只看五个数也能排掉大半：**收入增速 vs 应收增速、净现比（经营现金流÷净利润）、毛利率 vs 同行、有息负债与货币资金、商誉÷净资产。**
- 五维打分（利润质量/现金质量/资产质量/治理与披露/估值位置），每维 0–5 分，打分必须能指到具体科目。

**硬性排除条件（命中一条即 `fail`）**：非标审计意见；经营现金流连续三年为负；商誉占净资产 >50%；净资产为负；有财务造假处罚记录；控股股东资金占用。

## 三、可视化概览（数据够了就出，不默认手搓）

- 一条命令：`stock_charts action=emit symbol=<代码>`，直接读 `stock_data` 里那五年数据，生成图表概览 HTML（返回 `url`，在侧边栏 `/stock-os/reports/<代码>-charts.html` 打开）。
- 只画有数据的图；缺的字段自动省略并在页脚列"未覆盖"，**绝不画预估线**。想看能画几张：`action=preview`。
- 强周期行业必须做季度图（拐点看毛利率，不看收入）——把 `quarters` 填进数据集就会自动生成。
- 非周期公司 10–12 张就够；图不是越多越好，**每张图只回答一个问题**。
- 图是证据的压缩，不是结论本身；读完图要回到 `verdict` 里写"哪张图支持哪一句"。

## 四、估值（给区间，不给点）

| 方法 | 用途 | 注意 |
|---|---|---|
| PE/PB 五年带 | 判断现在处于自身历史的什么位置 | 亏损年份 PE 断点，不画 |
| 反向 DCF | 问"现价隐含了多少增长"，比预测增长容易 | 用 FCFE 就必须用 Ke，不能混 WACC |
| 情景三档 | 悲观/中性/乐观，各给一个"什么条件下成立" | 三档都要能自圆其说 |
| 股息/回购收益率 | 现金回报的下限 | 分红率 >100% 不可持续 |

结论写成："现价对应 X 倍 PE，处在五年 30% 分位；要支撑现价，未来三年需要年化 18% 的利润增长。"——这句话可以被证伪，比"估值合理"有用一百倍。

## 五、内部人行为（最容易漏、也最直白的一块）

| 项目 | 看什么 |
|---|---|
| 解禁 | 未来 12 个月的解禁时间表与规模占比（超过流通盘 10% 要警惕） |
| 增减持 | 大股东/高管净减持方向；增持是否真金白银（金额 vs 承诺） |
| 股权激励 | 行权条件是"跳一跳够得着"还是"闭眼过"；考核指标是收入还是利润 |
| 回购 | **回购注销**（真回报）vs 回购用于激励（左手倒右手） |
| 质押 | 控股股东质押比例 >70% 视为风险信号 |

## 七、降级规则（没有数据时）

- **唯一的例外**：确实拿不到数据 → `verdict = na`（`na` 不要求数据集完整，但必须在结论里写清缺什么、去哪拿、补上后能解锁什么判断）。
- 没有行情数据：只给研究结论，不给估值结论，`verdict` 不得为 `pass`。
- 没有行业对比数据：五维里的"估值位置"记 0 分并注明缺数据，不能用自身历史代替同行。
- 关键项（现金流、审计意见、商誉）缺失且无法补齐：`verdict = na`，不要用 `force` 去凑一个 `watch`。
