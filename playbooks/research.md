# ① 买前调研手册

目标：在花一分钱之前，把这笔投资变成一个**可以被证伪的判断**。输出只有一个东西——`verdict`，以及支撑它的证据出处。

## 一、行业与生意（先看生意，再看报表）

| 问题 | 要求 |
|---|---|
| 这门生意卖什么、卖给谁、怎么收钱 | 一句话讲清，出现"综合解决方案"这类词就重写 |
| 行业空间与增速 | 给数字与来源，不要"前景广阔" |
| 行业集中度与公司位置 | CR5/市占率；份额在升还是在降 |
| 周期位置 | 强周期行业必须判断"在周期的哪一段"，并说明依据 |
| 上下游议价 | 谁能占款：应收、预付、应付、合同负债四个方向的强弱 |
| 护城河类型 | 品牌 / 成本 / 网络 / 转换成本 / 牌照，**必须给证据**（毛利率差、客户留存、单吨成本对比） |

护城河的判据只有一条：**同样的东西，它凭什么能持续比同行多赚，或同样赚钱却更难被替代。** 说不出证据的，就是没有。

## 二、财务底稿（用已有的八章笔记，不重新发明）

- 底稿：`16_财报分析笔记_第1-8章合集.md`，按第 2/3/4 章的顺序过一遍三张表。
- 排雷：用第 20 份结论报告里的 12 项固定检查 + 6 条硬性排除条件。
- 只看五个数也能排掉大半：**收入增速 vs 应收增速、净现比（经营现金流÷净利润）、毛利率 vs 同行、有息负债与货币资金、商誉÷净资产。**
- 五维打分（利润质量/现金质量/资产质量/治理与披露/估值位置），每维 0–5 分，打分必须能指到具体科目。

**硬性排除条件（命中一条即 `fail`）**：非标审计意见；经营现金流连续三年为负；商誉占净资产 >50%；净资产为负；有财务造假处罚记录；控股股东资金占用。

## 三、可视化概览（按需，不默认做）

- 模板：`22_可视化图表概览_存储行业.html` 的 20 图结构，换数据即可。
- 强周期行业必须做季度图（拐点看毛利率，不看收入）。
- 非周期公司做年度 10–12 张就够；图不是越多越好，**每张图只回答一个问题**。

## 四、估值（给区间，不给点）

| 方法 | 用途 | 注意 |
|---|---|---|
| PE/PB 五年带 | 判断现在处于自身历史的什么位置 | 亏损年份 PE 断点，不画 |
| 反向 DCF | 问"现价隐含了多少增长"，比预测增长容易 | 用 FCFE 就必须用 Ke，不能混 WACC |
| 情景三档 | 悲观/中性/乐观，各给一个"什么条件下成立" | 三档都要能自圆其说 |
| 股息/回购收益率 | 现金回报的下限 | 分红率 >100% 不可持续 |

结论写成："现价对应 X 倍 PE，处在五年 30% 分位；要支撑现价，未来三年需要年化 18% 的利润增长。"——这句话可以被证伪，比"估值合理"有用一百倍。

## 五、内部人行为（最容易漏、也最直白的一块）

| 项目 | 看什么 |
|---|---|
| 解禁 | 未来 12 个月的解禁时间表与规模占比（超过流通盘 10% 要警惕） |
| 增减持 | 大股东/高管净减持方向；增持是否真金白银（金额 vs 承诺） |
| 股权激励 | 行权条件是"跳一跳够得着"还是"闭眼过"；考核指标是收入还是利润 |
| 回购 | **回购注销**（真回报）vs 回购用于激励（左手倒右手） |
| 质押 | 控股股东质押比例 >70% 视为风险信号 |

## 六、输出

```
verdict: pass | watch | fail | suspect | na
一句话结论：<动词 + 对象 + 条件>
硬性排除：<命中的条目，没有则空>
待跟踪异常：<2–3 条，每条带"下次看什么数据能确认/排除">
数据截止：<财报期 / 行情日期>
```

## 七、降级规则（没有数据时）

- 没有行情数据：只给研究结论，不给估值结论，`verdict` 不得为 `pass`。
- 没有行业对比数据：五维里的"估值位置"记 0 分并注明缺数据，不能用自身历史代替同行。
- 关键项（现金流、审计意见、商誉）缺失且无法补齐：`verdict = na`，写清缺什么、去哪拿。

## 八、自检

- 我有没有因为已经想买，而把风险写成"需关注"？
- 这个判断，能不能让一个陌生人只看我写的三句话就复现？
